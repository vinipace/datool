# Documentation illustrations

These assets are intentionally authored documentation, not operational evidence.

- `evaluation-loop.svg`: conceptual workflow diagram.

When refreshing screenshots, use a disposable local project and the documented examples. Keep credentials, customer traces, private hostnames, and raw execution exports out of this directory. The validation harness and execution artifacts remain in ignored `artifacts/` or outside the repository.
